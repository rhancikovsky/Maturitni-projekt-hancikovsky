# Flappy Bird - databaze, krok 1

- `database.sql` vytvori tabulky `users` a `scores`.
- `queries.sql` obsahuje ukazkove dotazy JOIN, WHERE a ORDER BY.
- `setup_database.py` vytvori soubor SQLite `game.db`.

## Spusteni
V terminalu ve slozce projektu spust:

```bash
py setup_database.py
```

Vznikne soubor `game.db`. Vzorova data a propojeni s hrou doplnime v dalsim kroku.
